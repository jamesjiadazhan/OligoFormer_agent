## Tools to implement (all invoke `python scripts/main.py ...` from the runtime copy with shell=False)
1. `predict_sirna_efficacy_from_mrna` — `--infer 1 -i1 <fasta>` (traverse every 19-nt window). Params: mrna_fasta_path (required); apply_functionality_filter: bool = True (False → `-nf`); include_toxicity: bool = False (`-tox`); toxicity_threshold: float = 50.0 (`--toxicity_threshold`, only meaningful with toxicity); output_dir. Returns per-record artifacts (<rec>.txt, _ranked.txt, _ranked_filtered.txt) and summary counts (windows, passing rows, func_filter distribution).
2. `predict_specific_sirna_efficacy` — `--infer 1 -i1 <mrna> -i2 <sirna>`; same flags. Upstream hazards (from executor evidence): siRNAs not matching any record are silently dropped; a record with ZERO matching siRNAs crashes the whole run (FileNotFoundError) and later records get no output; siRNA lines are not upper-cased/T→U converted; blank lines trigger the 19-nt error. Recommended I/O adaptation (no scientific change): pre-scan which records contain the reverse complement of each siRNA using the same matching rule as infer.py (re.search(antiRNA(siRNA), mRNA) after the same mRNA normalisation .upper().replace('T','U')); pass upstream only records with ≥1 match (single run), and report `unmatched_records` and `unmatched_sirnas` in the result. Error clearly if no siRNA matches any record. Reject siRNAs that are not exactly 19 nt of A/C/G/U (upstream would raise or misbehave) — do not silently convert.
3. `screen_sirna_offtarget` — `--infer 1 -i1 <mrna> -off` (+ `-tox` when include_toxicity; func filter flag as tool 1), `--pita_threshold`, `--targetscan_threshold`, `--utr`/`--orf` reference files (defaults: runtime's off-target/ref/100_human_UTR.txt and 100_human_ORF.txt; allow user paths, must exist & be non-empty). DO NOT expose `-top/--top_n` (executor found the top-N branch writes mislabelled sequences, attaching PITA/TargetScan scores to the wrong rows) and DO NOT expose `-a/--all_human` (broken: missing refs, silent all-NaN scores). After the run, verify data/infer/<rec>/pita.tab has its header and ≥1 data row and targetscan.tab is non-empty, and that pita_score/targetscan_score columns are not all-NaN — otherwise raise an MCP error (upstream ignores os.system failures). Return result tables plus copies of pita.tab and targetscan.tab per record. Runtime ~3–7 min for example.fa — set a generous timeout.
4. `compare_sirna_mismatch_kon` — `-m 1`, stdin "<base>\n<mismatched>\n". Params base_rna, mismatched_rna (19-nt A/C/G/U; validate — upstream gives KeyError on T/lowercase). Parse last non-empty stdout line as float; return {kon, ...}. No files → artifacts may be empty list.
5. `scan_sirna_mismatch_variants` — `-m 2|3` via stdin "<base>\n", `--output_dir <dir>` (mismatch.py writes output_dir + '/result/mismatch.txt'; pre-create <dir>/result; no trailing slash). Param max_mismatches: Literal[2, 3] = 2 (3 → 27,759 rows, ~95 s). Return the mismatch.txt artifact and counts per num_mismatch.
